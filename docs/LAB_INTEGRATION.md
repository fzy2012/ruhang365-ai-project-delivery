# 入行实验室接入合同

## 已确认产品关系

- 独立项目：方法、Skill、模板、评测和版本的真相源。
- RHZL：交付与 Workflow 承接系统。
- 什么值得用：Resource/Capability 的发现与推荐层。
- 入行实验室：入行365工具孵化与验证入口。本项目基于 Ponytail v4.9.0 的核心 Skill 组件改造，不标记为完全原创。

本项目加入入行实验室，但不建设独立网站，不把 Skill 全量复制进 RHZL。

## 建议入口

| 位置 | 作用 |
|---|---|
| `/tools/lab/ai-project-delivery` | 独立产品介绍、适用判断、开始入口和边界说明 |
| `/tools/lab` | 入行实验室列表卡片 |
| `/tools` | 标记“入行实验室孵化”的 Resource 条目，并清楚显示 Ponytail 来源 |
| Workflow 节点 | 在用户真实项目任务中按场景推荐 |

最终路由以接入时当前 RHZL 代码、合同和命名冲突检查为准。

## 页面最小价值

页面不能只是介绍 Skill，应让用户完成一次真实开始动作：

1. 输入或描述想完成的项目；
2. 判断任务复杂度和是否需要自研；
3. 获得下一步所需材料或可复制的 Skill 启动指令；
4. 清楚知道哪些决定由自己做、哪些由 AI 负责；
5. 能进入 RHZL 的后续 Workflow，而不是停在静态说明页。

## 建议元数据

- 产品名：AI 全流程项目共创与交付框架
- 短名称：AI 项目交付向导
- 类型：Skill / Workflow Framework
- 品牌：入行实验室孵化 / 基于 Ponytail v4.9.0 改造
- 核心结果：项目决策卡、双层验收基线、验证证据和项目交付卡
- 隐私边界：不要求用户在聊天中提交密码、密钥或 Cookie
- 状态字段：本地 V1、公开 Core、Preview、Production 分别记录

## 接入前置条件

1. Skill 结构验证通过。
2. 三类评测案例已冻结。
3. 至少完成一次独立新任务的完整模式前向评测。
4. 明确公开 Core 与许可证决策。
5. 从最新 `origin/main` 创建干净 RHZL worktree。
6. 重新读取 RHZL 当前合同、`AGENTS.md`、状态和目标文件。

## 发布闸门

```text
本仓 V1 验证
→ 公开/私有与许可决定
→ RHZL 只读方案和验收确认
→ 干净 worktree 实施
→ 本地测试与浏览器验证
→ Preview 用户验收
→ 明确合并授权
→ Production Ready 与公开路径验证
```

任何前置阶段成功都不能替代后续阶段证据。
